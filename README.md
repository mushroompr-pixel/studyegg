# 공부알 탐험대 (Study Egg Adventure)

퀴즈를 풀어 능력치를 키우고, 알을 차서 새로운 지역을 탐험하고, 펫을 모아 도감을 완성하는 픽셀 아트 힐링 게임.
배틀은 없다. 수집 · 성장 · 탐험 · 도감 완성에 집중한다.

---

## 실행 방법

### 1) 가장 간단한 방법

`index.html` 을 더블클릭해서 브라우저로 연다.

### 2) 로컬 서버로 열기 (권장)

폰트·저장 기능이 가장 안정적으로 동작한다.

```bash
python -m http.server 8777
```

브라우저에서 `http://localhost:8777` 접속.

> 진행 상황은 브라우저의 `localStorage` 에 자동 저장된다.
> 초기화는 게임 안의 **⚙ 설정 → 처음부터 다시 시작**.

## 배포 (mushroomprincess.net)

서버 코드가 없는 **정적 사이트**라 파일만 올리면 끝난다. 전체 195KB.

올릴 것: `index.html` · `css/` · `js/` · `icons/` · `favicon.png` · `manifest.webmanifest`
올리지 말 것: `.claude/` (로컬 개발 설정)

도메인은 **가비아**에 등록되어 있고 2026-09-17 기준 A 레코드가 없다.

### 권장: Cloudflare Pages (무료)

정적 파일 요청과 대역폭이 **무제한**이고, 월 500회까지 배포할 수 있다.
커스텀 도메인도 무료. (2026-09 기준 공식 문서)

1. 가비아 → My가비아 → **네임서버를 Cloudflare 것으로 변경**
   (Cloudflare 가입 후 도메인을 추가하면 지정할 네임서버 2개를 알려준다. 무료)
2. Cloudflare 대시보드 → **Workers & Pages → Create → Pages → Upload assets**
   → 이 폴더를 드래그 (깃·명령어 불필요)
3. 프로젝트 → **Custom domains → Set up a domain** → `game.mushroomprincess.net`
   (네임서버가 Cloudflare면 DNS 레코드는 자동으로 잡힌다)
4. HTTPS 인증서 자동 발급

네임서버를 Cloudflare로 옮기면 루트 도메인(`mushroomprincess.net`)에도
CNAME처럼 바로 붙일 수 있다 — 원래 DNS 규칙상 루트에는 CNAME을 못 쓴다.

### 대안

- **가비아 웹호스팅**을 이미 쓰고 있다면 FTP로 `public_html/` 아래에 그대로 업로드.
  네임서버를 안 건드려도 되는 가장 간단한 길
- **GitHub Pages** — 무료, 요금 청구 없음. 저장소가 **공개**여야 한다 (무료 계정 기준).
  소프트 한도: 사이트 1GB, 대역폭 월 100GB, 빌드 시간당 10회.
  가비아 DNS에 `game` CNAME → `아이디.github.io.` 또는 루트(`@`)에 A 레코드 4개
  (`185.199.108.153` / `109.153` / `110.153` / `111.153`) 후 저장소 Settings → Pages → Custom domain
- **Netlify** — 드래그 배포는 제일 쉽지만 무료 플랜이 **월 300 크레딧** 제한이다.
  배포 1회가 15 크레딧이라 **월 20회 배포**면 소진된다 (대역폭 20크레딧/GB, 요청 2크레딧/1만건).
  한도를 넘으면 요금이 청구되는 게 아니라 **다음 달까지 사이트가 정지**되고,
  한 프로젝트가 넘으면 계정의 모든 프로젝트가 같이 멈춘다.
  게임을 자주 고쳐 올릴 계획이면 맞지 않는다

### 배포 후

- **저장 데이터는 도메인마다 따로다.** `localhost` 에서 하던 진행 상황은 넘어가지 않는다
- 휴대폰·태블릿에서 접속 후 **홈 화면에 추가**하면 주소창 없는 앱처럼 실행된다 (매니페스트 포함됨)
- 파일을 고쳐 다시 올렸는데 안 바뀌면 브라우저 강력 새로고침 (`Ctrl+Shift+R`)

## 핵심 게임 루프

```
과일 발견 → 과일 클릭 → 퀴즈 풀이 → 능력치 상승
   → 알 차기 → 등급 결정 → 지역 도착 → 알 획득
   → 부화장 배치 → 시간 + 퀴즈로 부화 → 펫 획득
   → 펫 정원 배치 → 코인 생산 → 장비 구매 → 더 먼 지역 탐험
```

## 등급과 지역

**등급 7단계** — 일반 / 희귀 / 영웅 / 전설 / 신화 / 초신화 / 신의 알
알이 공중에 있는 동안 확률적으로 등급이 결정되고, 색이 단계별로 바뀐다.

**지역 11곳** — 도착 거리(m)로 결정된다.

| 지역 | 거리 | 지역 | 거리 |
|---|---|---|---|
| 초록숲 | 0 | 달빛숲 | 3,550 |
| 호수 | 320 | 무지개 왕국 | 4,500 |
| 바다 | 760 | 수정 동굴 | 5,550 |
| 화산 | 1,300 | 우주 평원 | 6,700 |
| 눈의 왕국 | 1,950 | 전설의 땅 | 8,000 |
| 하늘섬 | 2,700 | | |

펫은 **지역 × 등급** 으로 결정된다 (11 × 7 = **77종**).

## 스킨 10종

기본 / 빨강 · 파랑 · 초록 / 황금 · 수정 / 무지개 · 오로라 / 신성 · 창조신

부화할 때 확률로 붙고, 행운 수치와 무지개 날씨가 확률을 올린다.
높은 등급 스킨일수록 코인 생산량도 늘어난다.

## 원소 제단

제단 8곳(화산 · 바다 · 얼음 · 숲 · 천둥 · 달빛 · 무지개 · 우주)이 각각 한 지역에 대응한다.

보관함에 있는 그 지역의 알을 바치면 제단이 채워지고, 다 채우면 **전설 이상 등급**의
해당 지역 알(예: 화산의 알)을 돌려준다. 제단 단계가 오를수록 필요한 알이 늘어나는 대신
돌려받는 알의 등급도 높아진다. 최대 10단계.

안전장치 두 가지:

- 제단이 준 알은 다시 바쳐지지 않는다 (보관함 개수에서도 빠진다)
- 바치기 전에 **어떤 등급의 알이 몇 개 나가는지 확인창**으로 보여준다 — 낮은 등급부터 나간다

예) 화산 제단을 채우면 화산의 알 → 화산룡 · 용암 군주 · 피닉스 같은 고등급 화산 펫.

## 먹이 주기 (친밀도)

먹이를 주면 하트가 쌓이고 12개마다 친밀도가 한 단계 오른다 (최대 10단계).
한 단계마다 그 펫의 코인 생산이 **+10%**.

| 먹이 | 가격 | 하트 |
|---|---|---|
| 🍓 산딸기 | 60 | +1 |
| 🍰 케이크 | 380 | +7 |
| 🍬 별사탕 | 2,400 | +50 |

정원 화면의 **먹이 주기** 패널에서 전체에게 한 번에, 펫을 눌러 나오는 상세창에서 한 마리씩 줄 수 있다.

## 정원 꾸미기

장식을 사면 정원 화면에 그려지고 **전체 코인 생산**이 올라간다.

울타리 +5% · 꽃밭 +7% · 연못 +10% · 큰 나무 +13% · 분수 +18% · 무지개 다리 +25% · 황금 조각상 +35%
(전부 모으면 +113%)

## 파일 구조

```
index.html          화면 레이아웃
css/style.css       픽셀 UI 스타일
js/data.js          등급 · 지역 · 펫 77종 · 스킨 · 과일 · 날씨 · 이벤트 · 제단 · 장식 · 먹이 · 상점
js/sprites.js       16x16 도트맵 스프라이트 렌더러 (펫/알/과일/플레이어)
js/quiz.js          레벨별 사지선다 퀴즈 생성기
js/state.js         상태 · 저장 · 확률/거리 계산 · 이벤트 · 제단 · 친밀도 규칙
js/ui.js            모달 · 토스트 · 사운드 · 퀴즈창
js/kick.js          알 차기 미니게임 (게이지 · 비행 · 등급 연출)
js/game.js          화면 전환과 각 화면 렌더링, 메인 루프
```

프레임워크·빌드 도구 없음. 외부 의존성은 픽셀 폰트(Galmuri) CDN 하나뿐이고,
연결이 안 되면 시스템 폰트로 자동 대체된다.
